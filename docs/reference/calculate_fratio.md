# calculate F-ratio

given a data matrix of samples (columns) and features (rows), and a
vector of classes (character or factor), calculate an F-ratio for each
feature.

## Usage

``` r
calculate_fratio(data, data_classes)
```

## Arguments

- data:

  the data matrix, with samples (columns) and features (rows)

- data_classes:

  what are the classes of the samples (columns)

## Value

vector
