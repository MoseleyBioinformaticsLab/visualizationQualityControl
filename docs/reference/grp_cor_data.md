# grp_cor_data

Example data used for demonstrating `median correlation`. A list with 2
named entries:

## Usage

``` r
data(grp_cor_data)
```

## Format

List with 2 entries, data and class

## Source

Robert M Flight

## Details

- data:

  a data matrix with 100 rows and 20 columns

- class:

  a character vector of 20 entries denoting classes

The data comes from two groups of samples, where there is ~0.85
correlation within each group, and ~0.53 correlation between groups.
